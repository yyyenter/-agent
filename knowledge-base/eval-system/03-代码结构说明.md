## 二、核心模块说明

### 2.1 metrics.py - 指标计算

**核心类**: `TaskCompletionMetric`

```python
@dataclass
class TaskCompletionMetric:
    accuracy_score: float = 0.0        # 准确率 (0-10)
    completeness_score: float = 0.0    # 完整性 (0-10)
    convergence_score: float = 0.0     # 收敛性 (轮次越少越好)
    overall_score: float = 0.0         # 综合得分
```

**主要方法**:
- `analyze_response(response, expected_elements)` - 分析输出完成度
- `analyze_convergence(adjustment_count, circuit_breaker_triggered)` - 分析收敛性
- `calculate_overall()` - 计算综合得分

### 2.2 dataset.py - 测试数据集

**核心类**: `TestDataset`

```python
@dataclass
class TestCase:
    id: str
    name: str
    input_message: str
    expected_output_contains: List[str]
    expected_elements: List[str]
    tags: List[str]
    priority: str
    is_complex: bool
```

**预设测试用例**:
- tc_001: tc_008 (详见 README)

### 2.3 evaluator.py - 自动化评估器

**核心类**: `AgentEvaluator`

```python
class AgentEvaluator:
    def __init__(self, test_dataset, api_base_url):
        self.test_dataset = test_dataset
        self.api_base_url = api_base_url
        self.results: List[EvaluationResult] = []
    
    async def evaluate_test_case(self, test_case) -> EvaluationResult
    async def run_evaluation(self, tags=None, max_cases=None) -> Dict
    def save_report(self, report, filepath=None):
```

**主要流程**:
1. 构建请求 payload
2. 调用 API (`/api/chat_stream`)
3. 解析 SSE 流响应
4. 计算指标
5. 保存结果

### 2.4 memory_evaluator.py - 记忆评估

**核心类**: `MemoryEvaluator`

**评估维度**:
- `evaluate_preference_extraction` - 偏好提取准确率
- `evaluate_context_consistency` - 上下文一致性
- `evaluate_memory_relevance` - 记忆相关性

## 三、数据流图

```
用户输入
    ↓
TestDataset (加载测试用例)
    ↓
AgentEvaluator.evaluate_test_case()
    ↓
asyncio.run(_call_api())
    ↓
HTTP POST /api/chat_stream
    ↓
SSE 流解析
    ↓
TaskCompletionMetric.analyze_response()
    ↓
计算各项得分
    ↓
EvaluationResult.to_dict()
    ↓
报告生成
```
