# 🔗 飞书 ↔ CrewAI Agent 连接说明

## 一句话总结

```
飞书用户发消息 → WebSocket 长连接推送 → do_p2_im_message_receive_v1()
→ _call_agent() → TravelWorkflow.kickoff() → 返回规划结果 → 飞书 API 回复用户
```

## 代码中 4 个关键连接点

在 `long_conn_bot.py` 中，用 `🔗 【Agent 连接点】` 标记了 4 个位置：

| 连接点 | 位置 | 作用 |
|--------|------|------|
| **连接点 1** | 文件顶部 import | 导入 CrewAI 模块 |
| **连接点 2** | `do_p2_im_message_receive_v1()` | 飞书消息入口，提取消息后调用 Agent |
| **连接点 3** | `_call_agent()` | 核心！把消息送入 TravelWorkflow |
| **连接点 4** | `_send_reply()` | 把 Agent 结果发回飞书 |

## 数据流转

```
用户输入:  "我想去杭州玩3天"
    │
    ▼
do_p2_im_message_receive_v1()
    解析飞书事件 → 提取 "我想去杭州玩3天"
    │
    ▼
_call_agent("我想去杭州玩3天", user_id="ou_xxx", chat_id="cch_xxx")
    │
    ├── MemoryManager: 管理会话记忆
    ├── _rewrite_query: 处理代词指代（补全上下文）
    └── TravelWorkflow.kickoff():
         ├── PlannerCrew: 分析 → is_complex=true, location="杭州"
         ├── TravelExpertCrew: 搜索杭州天气+景点 → 写草案
         ├── ValidatorCrew: 质检 → [通过] 或 [重做]
         └── 返回 final_report: "以下是您的杭州3日游行程..."
    │
    ▼
_send_reply(open_id, final_report)
    调用飞书 API → 用户收到回复
```
