<title>01-eval集思路与架构</title>

<h1>一、设计思路</h1>

<h2>1.1 为什么需要评估体系？</h2>

<p>传统测试方法的局限性：</p>

<table>
  <colgroup><col span="2" width="150"/><col width="300"/></colgroup>
  <thead>
    <tr><th background-color="light-gray">传统方法</th><th background-color="light-gray">问题</th><th background-color="light-gray">评估体系的改进</th></tr>
  </thead>
  <tbody>
    <tr><td>人工测试</td><td>成本高、难以复现、主观性强</td><td>自动化执行、客观量化</td></tr>
    <tr><td>单次测试</td><td>无法追踪长期变化</td><td>持续评估、趋势分析</td></tr>
    <tr><td>黑盒测试</td><td>无法分析内部协作</td><td>多维度指标、过程追踪</td></tr>
    <tr><td>功能测试</td><td>只验证是否工作</td><td>性能、质量、效率全维度</td></tr>
  </tbody>
</table>

<h2>1.2 评估体系的设计原则</h2>

<callout emoji="⭐" background-color="light-blue" border-color="blue">
  <p><b>四维评估模型</b></p>
  <p><b>1. 任务完成度</b> → 结果质量</p>
  <p><b>2. 智能体协作</b> → 过程效率</p>
  <p><b>3. 记忆系统</b> → 上下文理解</p>
  <p><b>4. 系统健康度</b> → 稳定性</p>
</callout>

<p><b>核心理念</b>：</p>
<ul>
  <li><b>量化优先</b>：所有指标必须可测量</li>
  <li><b>分层设计</b>：从宏观到微观，层层递进</li>
  <li><b>自动化</b>：支持持续集成/持续评估</li>
  <li><b>可解释</b>：每个指标都有明确的业务含义</li>
</ul>

<hr/>

<h1>二、量化指标体系</h1>

<h2>2.1 任务完成度 (Task Completion)</h2>

<p>衡量 Agent 最终输出是否满足用户需求。</p>

<table>
  <colgroup><col span="1" width="140"/><col span="1" width="200"/><col span="1" width="50"/><col span="1" width="200"/></colgroup>
  <thead>
    <tr><th background-color="light-gray">指标</th><th background-color="light-gray">计算公式</th><th background-color="light-gray">满分</th><th background-color="light-gray">说明</th></tr>
  </thead>
  <tbody>
    <tr><td><b>准确率 (Accuracy)</b></td><td>基于关键字匹配和语义理解</td><td>10</td><td>输出符合用户需求的程度</td></tr>
    <tr><td><b>完整性 (Completeness)</b></td><td>(已包含要素数 / 期望要素数) × 10</td><td>10</td><td>行程包含时间、地点、交通等要素的完整度</td></tr>
    <tr><td><b>收敛性 (Convergence)</b></td><td>10 - max(0, 调整轮次 - 2) × 1.5 - 熔断惩罚</td><td>10</td><td>多少轮次完成（轮次越少越好）</td></tr>
    <tr><td><b>综合得分</b></td><td>Accuracy×0.4 + Completeness×0.35 + Convergence×0.25</td><td>10</td><td>加权平均</td></tr>
  </tbody>
</table>

<p><b>要素覆盖度检查清单</b>：</p>

<pre lang="python" caption="要素检查清单">
<code>EXPECTED_ELEMENTS = [
    "时间安排",  # 是否有"天"、"上午"、"下午"等时间标记

    "预算",      # 是否提及"预算"、"花费"、"价格"
]</code></pre>

<h2>2.2 智能体协作 (Collaboration)</h2>

<p>衡量 Planner → Execute → Validator 三个 Crew 的协作效率。</p>

<table>
  <colgroup><col span="1" width="140"/><col span="1" width="150"/><col span="1" width="50"/><col span="1" width="250"/></colgroup>
  <thead>
    <tr><th background-color="light-gray">指标</th><th background-color="light-gray">数据来源</th><th background-color="light-gray">满分</th><th background-color="light-gray">说明</th></tr>
  </thead>
  <tbody>
    <tr><td><b>路由正确率</b></td><td>intent_router 输出</td><td>10</td><td>Planner 决策是否合理（旅行 vs. 闲聊）</td></tr>
    <tr><td><b>工具调用有效性</b></td><td>工具调用日志</td><td>10</td><td>WeatherTool、MemoryTool 的命中率</td></tr>
    <tr><td><b>质检反馈质量</b></td><td>Validator 输出</td><td>10</td><td>反馈是否有明确指导意义（通过/重做/继续）</td></tr>
  </tbody>
</table>

<p><b>协作流程追踪</b>：</p>

<pre lang="text" caption="ReAct Flow 协作流程">
<code>用户消息
    ↓
[PlannerCrew] 决策 → is_complex? / simple_answer?
    ↓ 是
[TravelExpertCrew] 执行 → 生成 draft_report
    ↓
[ValidatorCrew] 质检 → feedback_type: pass/error/adjust/continue/ask_user
    ↓ 需要修正
[TravelExpertCrew] 执行 (修正) ← 循环
    ↓
最终报告</code></pre>

<callout emoji="🧠" background-color="light-purple" border-color="purple">
  <p><b>四级记忆存储架构</b></p>
  <p><b>情节记忆 (桶3)</b> → Redis List → 原始对话轮次</p>
  <p><b>工作记忆 (桶5)</b> → Redis Hash → 临时行程约束</p>
  <p><b>工具缓存 (桶4)</b> → Redis KV → 全局工具缓存（L1/L2/L3 三层匹配）</p>
  <p><b>语义记忆 (桶6)</b> → SQLite user_memory 表 → 用户长期偏好（动态 KV 结构）</p>
</callout>

<h1>四、使用方法</h1>

<h2>4.1 CLI 快速评估</h2>

<pre lang="bash" caption="CLI命令">
<code># 快速评估
uv run python -m agent_test0.eval.cli quick

# 完整评估
uv run python -m agent_test0.eval.cli run --tags "planning" --count 10</code></pre>

<h2>4.2 Python API</h2>

<pre lang="python" caption="Python调用示例">
<code>from agent_test0.eval import AgentEvaluator, TestDataset

evaluator = AgentEvaluator(TestDataset(), "http://localhost:8000")
report = await evaluator.run_evaluation(max_cases=5)
print(f"平均得分: {report['average_scores']['overall']:.2f}/10")</code></pre>
