# Agent 评估体系：使用文档

## 一、快速开始

### 1.1 安装依赖

```bash
uv add aiohttp pytest
```

### 1.2 运行评估

```bash
# 方式 1: CLI 命令
uv run python -m agent_test0.eval.cli quick

# 方式 2: Python 脚本
uv run python src/agent_test0/eval/run_eval.py

# 方式 3: 交互式示例
uv run python src/agent_test0/eval/examples.py
```

## 二、CLI 使用说明

### 2.1 命令列表

```bash
# 快速评估（默认3个用例）
uv run python -m agent_test0.eval.cli quick --count 3

# 运行完整评估
uv run python -m agent_test0.eval.cli run \
    --tags "planning" \
    --count 10 \
    --url http://localhost:8000

# 运行单个测试
uv run python -m agent_test0.eval.cli test tc_003
```

### 2.2 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--url` | API 地址 | http://localhost:8000 |
| `--tags` | 标签过滤，逗号分隔 | 全部 |
| `--count` | 测试用例数量 | 全部 |
| `--name` | 评估名称 | default |
| `--output` | 输出文件 | eval_results_{name}.json |

## 三、Python API

### 3.1 基础使用

```python
import asyncio
from agent_test0.eval import AgentEvaluator, TestDataset

async def main():
    evaluator = AgentEvaluator(TestDataset(), "http://localhost:8000")
    report = await evaluator.run_evaluation(max_cases=5)
    
    # 打印报告
    print(f"平均得分: {report['average_scores']['overall']:.2f}/10")
    print(f"通过率: {report['summary']['pass_rate']:.1%}")

asyncio.run(main())
```

### 3.2 过滤测试

```python
dataset = TestDataset()

# 按标签过滤
planning_cases = dataset.filter_test_cases(tags=["planning"])

# 按优先级过滤
high_priority = dataset.filter_test_cases(priority="high")
```

### 3.3 单个测试

```python
test_case = dataset.test_cases[2]  # tc_003
result = await evaluator.evaluate_test_case(test_case)

print(f"得分: {result.metrics['overall_score']:.2f}")
print(f"通过: {result.passed}")
```

## 四、自定义评估

### 4.1 添加新测试用例

```python
from agent_test0.eval.dataset import TestCase

new_case = TestCase(
    id="tc_009",
    name="自定义测试",
    input_message="我想去深圳玩",
    expected_elements=["时间安排", "地点", "交通方式"],
    tags=["custom"],
    priority="normal",
    is_complex=True
)

dataset.add_test_case(new_case)
```

### 4.2 添加自定义指标

```python
from agent_test0.eval.metrics import TaskCompletionMetric

class CustomMetric(TaskCompletionMetric):
    def calculate_custom_score(self, response: str) -> float:
        # 自定义评估逻辑
        if "完美" in response:
            return 10.0
        elif "一般" in response:
            return 5.0
        return 0.0
```

## 五、问题排查

### 5.1 常见问题

**Q: 评估失败，提示连接拒绝**
```
A: 检查 API 服务是否启动: uv run python src/agent_test0/main.py
```

**Q: 测试用例加载失败**
```
A: 检查测试用例 JSON 格式是否正确
```

**Q: 评估结果不准确**
```
A: 检查 expected_elements 是否与实际输出匹配
```

## 六、集成到 CI/CD

```yaml
# .github/workflows/evaluate.yml
name: Agent Evaluation

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  evaluate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      - name: Install dependencies
        run: |
          uv sync
      - name: Run evaluation
        run: |
          uv run python src/agent_test0/eval/run_eval.py
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
      - name: Upload results
        uses: actions/upload-artifact@v3
        with:
          name: eval-results
          path: eval_results_*.json
```
